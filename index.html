    01

    Ho già un MP3 sull’iPhone

    La soluzione più semplice

    1. Salva il file audio nell’app File dell’iPhone, in “Download” o “Sul mio iPhone”.
    2. In Music Box tocca + → File audio dal telefono e seleziona il file.
    3. Alla domanda “Lo metto online?” scegli Metto online. Se non hai configurato la chiave, vai su + → Pubblica senza PC.

    Importante: il file viene aggiunto prima sul dispositivo. La pubblicazione online riesce solo se il PC di casa è raggiungibile oppure se il servizio remoto e la relativa chiave sono configurati. Controlla il messaggio finale: “salvato qui” non significa “online”.

    02

    Ho un link YouTube

    Per una canzone disponibile come video

    1. Da YouTube premi Condividi → Copia link.
    2. Torna in Music Box e scegli + → Link YouTube.
    3. Music Box mette la richiesta in coda al server online, anche col PC spento. Quando l’MP3 viene pubblicato compare nella libreria e si suona dal player standard. Se YouTube blocca il download, compare un errore.

    Un link messo in coda non è ancora un MP3 scaricato. Se il programma sul PC o il servizio di coda non sono disponibili, l’importazione non si completa.

    03

    Voglio una playlist Spotify

    Importa un gruppo di brani

    1. Tocca + → Playlist Spotify e segui l’importazione.
    2. Controlla le corrispondenze e gli eventuali duplicati prima di considerare i brani disponibili.

    Importare l’elenco di titoli non significa che tutti gli MP3 siano già pubblicati o funzionanti. Per ottenere gli audio può servire il programma sul PC.

    04

    Con il computer spento?

    Dipende da cosa stai importando

    • File MP3 già presente sull’iPhone: si può aggiungere subito alla libreria locale. Per metterlo online serve il servizio di pubblicazione con chiave, se il PC non è raggiungibile.
    • Link YouTube: la richiesta va in coda sul server; un MP3 compare solo dopo una conversione e pubblicazione riuscite.
    • Solo offline: usa Altro → Scarica per offline per conservare sul telefono le canzoni che sono già nella libreria.
    05

    Posso usare l’app GitHub?

    Per aggiungere brani, meglio Music Box

    L’app ufficiale GitHub non offre un normale caricamento di MP3 nei repository. Da Safari → github.com puoi caricare file nel repository, ma l’MP3 non entra automaticamente nel catalogo Music Box: servono anche i dati corretti del brano e la pubblicazione dell’app.

    Evita di mettere i file manualmente nel repository se vuoi soltanto aggiungere una canzone alla libreria. Usa il tasto + di Music Box.

    Se non vedo la canzone o non si riproduce
    • Controlla di aver scelto il profilo corretto (Ste, Diego, Emanuele…).
    • Se il file è solo sul telefono, prova ad aprire Music Box sullo stesso dispositivo.
    • Se il PC era spento, verifica che il servizio remoto sia configurato e che l’invio sia riuscito.
    • Cerca trova canzoni già presenti: non le scarica. Riconosci titoli da uno screenshot non importa MP3.
    • Scarica per offline conserva un brano già presente: non aggiunge nuove canzoni online.
